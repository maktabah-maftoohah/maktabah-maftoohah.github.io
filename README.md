# Maktabah Maftoohah (المكتبة المفتوحة) — Master Portal

> **Live Organization Portal:** [https://maktabah-maftoohah.github.io/](https://maktabah-maftoohah.github.io/)

Master organization landing page, interactive multi-collection catalogue, and unified search directory for **Maktabah Maftoohah** — an open-source, zero-build digital library dedicated to authentic Islamic heritage.

## Features
- **Central Catalogue (46 Canonical Works)**: Comprehensive directory of Quran, Kutub at-Tis'ah, Early Musannaf, Hadith Ahkam, Classical Tafsir, Rijal, and Seerah.
- **Instant Search & Filtering**: Real-time filtering by category, compilation type, author, era, and publication status.
- **Zero-Build Vanilla ES6**: Fast, lightweight, and completely serverless — running natively in any modern web browser.
- **Offline-First PWA**: Progressive Web App with caching and responsive interface across mobile, tablet, and desktop.
- **Dual-Language**: Bahasa Melayu (default) and English.

## Local Development
```bash
python scripts/serve.py --port 8000
# Open http://localhost:8000 in your browser
```
